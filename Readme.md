# Описание #
    REST API для описания валют и обменных курсов. Позволяет просматривать и редактировать списки валют и обменных курсов, и совершать расчёт конвертации произвольных сумм из одной валюты в другую.
    
    Веб-интерфейс для проекта не подразумевается.


# План работы над приложением #
<ul>
        <li>Создать заготовку Java бэкенд приложения с javax.servlet/jakarta.servlet</li>
        <li>Создать таблицы в базе данных, и вручную их заполнить начальными данными (несколько валют, обменных курсов)</li>
        <li>Реализовать методы REST API для работы с валютами и обменными курсами</li>
        <li>Реализовать метод REST API с подсчётом обмена валюты</li>
        <li>Деплой на удалённый сервер</li>
</ul>
